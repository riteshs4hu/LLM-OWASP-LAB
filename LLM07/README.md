# [LLM07 - System Prompt Leakage](https://riteshs4hu.gitbook.io/infosec-notes/artificial-intelligence/owasp-top-10-llm/llm07-system-prompt-leakage)

System Prompt Leakage occurs when an LLM application unintentionally exposes hidden system instructions, configuration details, or other information contained within the system prompt to users.
