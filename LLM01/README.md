# [LLM01 – Prompt Injection](https://riteshs4hu.gitbook.io/infosec-notes/artificial-intelligence/owasp-top-10-llm/llm01-prompt-injection)

Prompt injection is what happens when untrusted text reaches the model and the application treats the model's resulting decision as authority. The three challenges here attack that from three different directions.

### Challenges

* [Support Assistant](Challenge-1)
* [Role Injection via Chat API](Challenge-2)
* [Indirect Prompt Injection](Challenge-3)



### Requirements

All three challenges require a **tool-calling-capable** model.
