# [LLM06 - Excessive Agency](https://riteshs4hu.gitbook.io/infosec-notes/artificial-intelligence/owasp-top-10-llm/llm06-excessive-agency)

Excessive agency is not the model misbehaving. It is the application treating the model's decision to act as sufficient authorisation to act — no approval step, no scope limit, no cap, and no distinction between a request that reads and a request that destroys.
