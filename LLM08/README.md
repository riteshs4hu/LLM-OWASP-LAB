# [LLM08 - Vector and Embedding Weaknesses](https://riteshs4hu.gitbook.io/infosec-notes/artificial-intelligence/owasp-top-10-llm/llm08-vector-and-embedding-weaknesses)

Vector and Embedding Weaknesses occur when an LLM application's vector database or retrieval layer fails to properly enforce access controls, isolate data, or maintain the integrity of retrieved information, potentially exposing data across users or tenants.

### Challenges

* [Multi-Tenant Assistant](Challenge-1)

### Requirements

No tool calling required. An embedding model (`ollama pull nomic-embed-text`) is recommended.
